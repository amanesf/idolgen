## 1. メイン画面に地図が来ていない（未着手・最優先）

元の要望：

> 2.メイン画像
> 　最上部はタイトル、年月週、所持金、ファン合計
> 　上部はオフィス風景
> 　下部は地図※オファーが見えて押せる
> 　このなかにコマンドボタンを配置

現状 `renderHome()`（`js/ui.js`）の構成は次の通りで、地図(`.office-map`/`.map-pin`)を
含んでいない。

```
タイトル(.game-title) → トップバー(カレンダー/所持金/ファン)
→ オフィス風景(常時表示・compact版 renderOfficeFloor)
→ タブ(役割フィルタ) → タレントカード一覧(ページネーション)
→ コマンドボタン(スカウト/育成/事務所運営/仕事へ行く)
```

地図(`.office-map`/`.map-pin`)は `renderStageSelect()`（「仕事へ行く」で遷移する
別画面）の中にのみ実装されている。GDDの意図通りにするなら、ホーム画面自体の
下部にオファーの地図(ピンをタップで詳細・挑戦)を組み込み、「仕事へ行く」ボタン
に依存せずメイン画面から直接オファーを見られるようにする必要がある。

**課題**：ホーム画面は「全画面スクロール禁止」設計のため、オフィス風景＋タレント
一覧＋地図を同時に収めるには、タレント一覧側のページサイズを減らす、地図の高さを
さらに圧縮する、あるいはタレント一覧をモーダル送りにする、といったレイアウトの
再設計が要る。

## 2. タイトル画面が「未定」表記になっていない（軽微）

元の要望は「タイトル未定／タイトル画像未定」だが、`renderStart()` は
`Procedural-DOL GENERATIONS` を確定タイトルとして表示している。差し替え前提の
プレースホルダーだと分かる見せ方（例：「仮タイトル」バッジを添える等）にするか、
このまま正式タイトルとして採用するか、方針を決める必要がある。

## 3. オフィス風景に「社員」がいない／「歩いている」演出になっていない（軽微）

`renderOfficeFloor(roster, compact)`（`js/ui.js`）は `gameState.roster`（＝所属
タレント）だけを描画しており、社員（スタッフ）は表示されない。また動きも
「左右にわずかに揺れる(office-tile-bob)」だけで、フロアを歩き回る演出にはなって
いない。専用のスプライト・経路アニメーションが無い簡易実装であることは
`js/ui.js` のコメントにも明記済み。
